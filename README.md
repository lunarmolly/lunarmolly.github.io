# Kirill Kovtun - Portfolio Website

A technical brutalist portfolio website for Kirill Kovtun, showcasing expertise in project management, data analytics, and software development with a documentation-style aesthetic.

## About

This personal portfolio website underwent a complete transformation from minimalist design to technical brutalism. Built with Bootstrap 5 and custom CSS, it features a monochrome, documentation-inspired design with table-based data presentation and technical codes. The site presents professional services, case studies, and contact information in a structured, code-like interface reminiscent of technical documentation.

## Design Evolution

- **V1.0 (May 2025)**: Modern minimalist design with soft colors and card-based layout
- **V2.0 (June 2025)**: Complete redesign to brutalist aesthetic with monochrome styling and table-based structure

## Features

- **Technical Brutalist Design**: Monochrome interface with documentation-style aesthetics
- **Table-Based Data Presentation**: All information structured in technical tables with codes

## Design Philosophy

The website embodies technical brutalism - a design approach that prioritizes function over form while maintaining a harsh, uncompromising aesthetic. Every element serves a purpose, with no decoration for decoration's sake. The monochrome color scheme and technical typography create an atmosphere of serious professionalism and technical competence.
