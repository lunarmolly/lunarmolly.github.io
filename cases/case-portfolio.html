История проекта

После накопления опыта в управлении проектами, аналитике данных и разработке, было принято решение создать собственный сайт-портфолио. Основной задачей было — не просто представить себя, а выделиться визуально и стилистически, создав запоминающуюся цифровую визитку.

Проект был реализован в свободное время, с упором на высокую настраиваемость, минимальные внешние зависимости и возможность дальнейшего масштабирования.

Клиент

Личный бренд — Ковтун Кирилл. Специализация: проектный менеджмент, анализ данных и разработка решений для малого и среднего бизнеса.

Цели проекта

  • Создать персональный сайт для представления компетенций, портфолио и услуг.
  • Обеспечить полную адаптивность и высокую производительность.
  • Сконцентрироваться на простоте добавления новых кейсов и разделов.
  • Разместить сайт на GitHub Pages без серверной части.

Особенности проекта

Сайт был разработан вручную с использованием Bootstrap 5, без шаблонов. Были внедрены следующие функции:

  • Навигация с бургер-меню, открывающимся на весь экран.
  • Плавные анимации появления блоков, кнопок и карточек.
  • Фильтрация кейсов по категориям.
  • Счётчики, активируемые при скролле до секции.
  • Эффекты при наведении на карточки и стек технологий.
  • Кастомная палитра: тёмный фон + акцентные оранжевый, жёлтый, зелёный цвета.
  • Минимализм, усиленный декоративными рамками и световыми акцентами.
  • Возможность удобно добавлять кейсы в отдельные HTML-файлы по шаблону.

Структура сайта

  • Hero: аватар, список компетенций и слоган.
  • Обо мне: краткое описание опыта, статистика, стек технологий.
  • Услуги: карточки с описанием и ценами.
  • Кейсы: интерактивная сетка, фильтрация по категориям, ссылки на отдельные страницы.
  • Контакты и CTA: формы связи, реквизиты, фиксированная кнопка Telegram.

Результаты

  • Сайт стал основным каналом презентации личного бренда и кейсов.
  • Создана единая точка входа для клиентов.
  • Отдельные страницы кейсов удобно масштабируются и наполняются.
  • Благодаря кастомному дизайну, сайт выделяется среди типовых лендингов и шаблонов Tilda/WordPress.

Срок разработки

3 недели в свободное время: от концепции до деплоя на GitHub Pages.
